TorrentDesk

0.3.0 · Help

Usage

Add or drop .torrent files. Select rows and use Start/Pause; without a selection the command affects all torrents.

Notification area (tray)

X and the Tray button hide the window while sessions continue. Click the icon to restore it. Right-click: Open, Start all, Pause all, Help, Exit. Only Exit shuts down the application and attempts stopped announces.

Language

The selector applies a language immediately and remembers your choice. English and Italian are included; JSON translation catalogs are extensible.

Counters and limitations

Upload and speed are simulated. All torrents are announced complete (left=0); files are not checked. HTTP/HTTPS, v1/hybrid support; UDP and pure v2 are unsupported. Profiles are not certified for current client/OS combinations.

About

Independent educational C++17 / Win32 project. The Flow logo was generated with imagegen and selected for TorrentDesk.
